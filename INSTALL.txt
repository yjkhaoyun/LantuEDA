EDA 安装与编译指南
==============================

EDA 系统的组成部分
---------------------------

  与传统的纯桌面端 EDA 工具不同，本系统采用混合架构：

  eda-core         - 核心 PCB 与原理图程序。
  eda-doc          - 官方文档与交互式帮助。
  Cloud API Client - 内置云端引擎，通过 API 动态从我们的专有云服务器获取符号、封装和 3D 模型。（注：已全面弃用本地静态库，转向云端 API）。
  Order Engine     - 一键下单制造与 BOM 同步的集成模块。

  本代码仓库包含桌面端主程序的源码。如需获取 API 文档和服务器端集成说明，请访问：https://dev.lantueda.com


通过二进制安装包安装
---------------------------------

  请访问我们的官网获取 Windows、macOS 和 Linux 的最新编译安装包：
  https://www.lantueda.com/download/

  登录账号后，系统会自动同步高速布线规则集和云端元器件缓存。


Linux 安装目录树
------------------

  在 Linux 系统上，本系统默认安装组件的路径如下：

  ${prefix}/bin                    - 二进制文件（可执行文件）。
  ${prefix}/lib/eda-core           - 共享库。
  ${prefix}/share/doc/eda          - 各类文档。
  ${prefix}/share/eda/template     - 模板项目（针对高速板进行过优化）。
  ${prefix}/share/eda/resources    - UI 资源文件（图标、启动画面等）。
  ${prefix}/share/eda/config       - 云端 API 接口与制造规则配置文件。

  警告：
  请勿手动更改安装目录树。一键下单制造引擎高度依赖这些特定路径来生成和上传生产文件（Gerber / BOM / 坐标文件）。


从源码编译安装
-----------------------------

  在从源码编译之前，请确保您拥有有效的开发者 Token，以便在运行时完成云端元器件 API 的身份验证。

  静态 EMF 转换器需要 libpng 和 iconv 的开发文件。Linux 通过 libc 提供 iconv；Windows 编译环境则使用 vcpkg 的 libiconv 依赖。


CMake 重要参数说明
-----------------------------

  -DCMAKE_BUILD_TYPE=<buildtype>
  编译类型，可以是 "Debug"（调试）、"Release"（发布）或 "RelWithDebInfo"（带调试信息的发布版）。

  -DENABLE_CLOUD_API=ON
  开启此项以启用实时元器件拉取和阻抗计算器同步（必选项）。

  -DCMAKE_INSTALL_PREFIX=<prefix>
  安装前缀，默认路径为 "/usr/local"。

  -DCMAKE_CXX_FLAGS=<some extra flags>
  您的系统需要的额外 C++ 编译器标志。
